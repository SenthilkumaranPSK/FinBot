# Security Policy 🛡️

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Place Gaurd team takes the security of our platform and user data very seriously.

If you discover a security vulnerability or critical issue:
1. **Do not disclose it publicly** in open GitHub issues.
2. Email full reproduction details to `security@placeguard.dev` or create a private GitHub Security Advisory.
3. We will acknowledge receipt within 48 hours and work on a prompt patch.

Thank you for keeping Place Gaurd safe!
